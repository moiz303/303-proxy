# 303-proxy Browser Extension

Браузерное расширение для перенаправления веб-трафика через прокси-сервер. Оно может пригодиться всем, кто заботится о своей интернет-безопасносити. Вся серверная часть уже развернута и работает, вам нужно только установить расширение из магазина Chrome.

## 🚀 Функциональность

*   **Автоматическое перенаправление трафика** - все запросы браузера автоматически идут через прокси-сервер
*   **Простой интерфейс** - включение/выключение прокси в один клик
*   **Стабильная работа** - серверная часть работает на мощном выделенном сервере
*   **Безопасность** - защищенное соединение между расширением и сервером

## 📦 Установка (30 секунд)

### Шаг 1: Установите расширение
1. Перейдите на страницу расширения **303-proxy** в Chrome Web Store
2. Нажмите кнопку **"Установить"**
3. Подтвердите установку в всплывающем окне браузера

### Шаг 2: Готово!
После установки расширение **303-proxy** автоматически подключится к работающему прокси-серверу. Просто нажмите на иконку расширения, чтобы включить или выключить прокси.

## 🛠️ Как пользоваться

1. **Включение/выключение:** Кликните на иконку расширения **303-proxy** в панели инструментов браузера
2. **Статус работы:** Индикатор показывает текущее состояние прокси
3. **Работа в фоне:** После включения всё работает автоматически

## ❓ Частые вопросы

**Q: Нужно ли мне что-то дополнительно настраивать?**  
A: Нет, расширение **303-proxy** уже полностью настроено и готово к работе сразу после установки.

**Q: Что делать, если прокси не работает?**  
A: Убедитесь, что расширение включено в настройках браузера и попробуйте перезагрузить страницу.

**Q: Можно ли использовать расширение в других браузерах?**  
A: В текущей версии расширение **303-proxy** доступно только для браузера Chrome.

**Q: Безопасно ли использование?**
A: Да, все соединения защищены, а серверная часть работает стабильно.
