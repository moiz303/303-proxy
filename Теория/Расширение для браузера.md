**Создание расширения для браузера, которое взаимодействует с вашим Python-проектом на сервере, включает несколько шагов**
1. Подготовка серверной части (Python-проект)

Ваш Python-проект должен быть доступен через HTTP API (например, через Flask, FastAPI или Django REST framework).
Пример на Flask:  
```python

from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/api/process', methods=['POST'])
def process_data():
    data = request.json
    # Обработка данных (ваша логика)
    result = {"status": "success", "data": data}
    return jsonify(result)

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

Запустите сервер (например, python app.py).
Убедитесь, что API доступно (например, через curl или Postman):
```bash
    curl.exe http://localhost:5050/api/process -X POST -H "Content-Type: application/json" -d '{"text": "Hello"}'
```
2. Создание расширения для браузера

Расширение состоит из:

- manifest.json — конфигурационный файл.

- Фонового скрипта (background.js) или popup-интерфейса.

- Опционально: content-скриптов для взаимодействия с веб-страницами.

Структура папки расширения:
text

my-extension  
├── manifest.json  
├── popup.html  
├── popup.js  
└── icon.png

Пример manifest.json (для Chrome/Edge):
```json
{
  "manifest_version": 3,
  "name": "My Python Extension",
  "version": "1.0",
  "description": "Расширение для работы с Python-бэкендом",
  "action": {
    "default_popup": "popup.html",
    "default_icon": "icon.png"
  },
  "permissions": ["activeTab", "scripting"]
}
```
Пример popup.html:  
```html
<!DOCTYPE html>
<html>
<body>
  <button id="sendData">Отправить данные</button>
  <script src="popup.js"></script>
</body>
</html>
```
Пример popup.js:  
```javascript
document.getElementById('sendData').addEventListener('click', async () => {
  const response = await fetch('http://localhost:5000/api/process', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ text: "Данные из расширения" })
  });
  const result = await response.json();
  alert(`Ответ сервера: ${JSON.stringify(result)}`);
});
```
3. Проверка CORS (важно!)

Браузеры блокируют запросы к localhost из расширений из-за политики CORS. Решения:

Вариант 1: Добавить заголовки CORS в Python-сервер:
```python
from flask_cors import CORS
CORS(app)  # Разрешить все origins (для разработки)
```

Вариант 2: Использовать chrome.webRequest или browser.proxy для обхода CORS (сложнее).

4. Загрузка расширения в браузер

- Откройте chrome://extensions/ в Chrome.

- Включите режим разработчика.

- Нажмите "Загрузить распакованное расширение" и выберите папку my-extension.

5. Деплой Python-проекта на сервер

Чтобы расширение работало у всех пользователей pазместите Python-проект на VPS (например, через gunicorn + nginx).
```bash
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

Обновите URL в popup.js:
```javascript
const response = await fetch('https://ваш-сервер.com/api/process', { ... });
```

6. Публикация расширения (опционально)

    Chrome Web Store: https://developer.chrome.com/docs/webstore/publish/

    Firefox Add-ons: https://addons.mozilla.org/developers/

Дополнительные возможности

- Content Scripts: Взаимодействие с открытыми страницами.

- Фоновые скрипты: Долгоживущие процессы.

- Хранение данных: chrome.storage для сохранения настроек.

Пример с Content Script

Если нужно отправлять данные с веб-страницы, добавьте в manifest.json:
```json
{
  "content_scripts": [
    {
      "matches": [
        "<all_urls>"
      ],
      "js": [
        "content.js"
      ]
    }
  ]
}
```

Создайте content.js:
```javascript
chrome.runtime.sendMessage({ action: "sendToPython", data: "Текст со страницы" });
```
Готово! Теперь ваше расширение может общаться с Python-бэкендом. Для более сложных сценариев изучите документацию Chrome Extensions API или WebExtensions для Firefox.

Вот минимальный "скелет" файла `popup.js` для подключения к серверу по кнопке **"Подключиться"** с обработкой успешного соединения и ошибок:

```javascript
// popup.js — базовый скелет для подключения к серверу

document.addEventListener('DOMContentLoaded', () => {
  const connectButton = document.getElementById('connectButton');
  const statusElement = document.getElementById('status');
  const serverUrl = 'http://ваш-сервер.com/api/connect'; // Замените на ваш URL

  connectButton.addEventListener('click', async () => {
    try {
      // Показываем статус "Подключение..."
      statusElement.textContent = 'Подключение...';
      statusElement.style.color = 'blue';

      // Отправляем запрос на сервер
      const response = await fetch(serverUrl, {
        method: 'POST', // или 'GET', в зависимости от вашего API
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ action: 'connect' }) // Опциональные данные
      });

      if (!response.ok) {
        throw new Error(`Ошибка HTTP: ${response.status}`);
      }

      const result = await response.json();

      // Успешное подключение
      statusElement.textContent = 'Успешно подключено!';
      statusElement.style.color = 'green';
      console.log('Ответ сервера:', result);

    } catch (error) {
      // Обработка ошибок
      statusElement.textContent = `Ошибка: ${error.message}`;
      statusElement.style.color = 'red';
      console.error('Ошибка подключения:', error);
    }
  });
});
```

---

### Как использовать:
1. Добавьте в `popup.html` кнопку и элемент для статуса:
   ```html
   <button id="connectButton">Подключиться</button>
   <p id="status">Готово к подключению</p>
   ```

2. Настройте `serverUrl` на ваш API-эндпоинт (например, `http://localhost:5000/connect` для локального сервера).


3. **Для работы с HTTPS** (если сервер использует SSL):
   ```javascript
   const serverUrl = 'https://ваш-сервер.com/api/connect';
   ```

---

### Дополнительные улучшения:
- **Таймаут запроса**:
  ```javascript
  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), 5000); // 5 сек.

  const response = await fetch(serverUrl, {
    signal: controller.signal,
    // ... остальные параметры
  });
  clearTimeout(timeoutId);
  ```

- **Сохранение состояния подключения**:
  Используйте `chrome.storage.local`, чтобы запоминать статус между перезагрузками:
  ```javascript
  // После успешного подключения
  await chrome.storage.local.set({ isConnected: true });

  // При загрузке popup
  const { isConnected } = await chrome.storage.local.get('isConnected');
  if (isConnected) {
    statusElement.textContent = 'Уже подключено';
  }
  ```

---

Этот код обрабатывает базовые сценарии подключения и ошибок. Подстройте его под ваш API!

Переадресация находится в двух местах:
1. Подключение к целевому серверу (строки 32-33):
    ``` python
    # 3. Подключаемся к целевому серверу
    remote_reader, remote_writer = await asyncio.open_connection(host, port)
    ```
Здесь прокси устанавливает соединение с реальным сервером (host:port), куда нужно переадресовать запрос.
2. Двунаправленная переадресация данных (строки 40-43):
    ```python
    # 4. Перенаправляем трафик в обе стороны
    await asyncio.gather(
        forward_data(remote_reader, writer),  # сервер -> клиент
        forward_data(reader, remote_writer)   # клиент -> сервер
    )
    ```

Это основная переадресация:  
forward_data(remote_reader, writer) - данные от сервера → клиенту
forward_data(reader, remote_writer) - данные от клиента → серверу  
Функция  forward_data читает данные из одного соединения и записывает в другое, создавая прозрачный туннель между клиентом и сервером.  
Здесь переадресуется первоначальный HTTP-запрос клиента на целевой сервер.

```bash
    #!/bin/bash
    # Запуск основного сервера (в фоне)
    cd /path/to/proxy_logic
    python proxy_logic.py &

    # Запуск Flask-связки
```

Запуск:
```bash
    chmod +x run_all.sh
    ./run_all.sh
```

```bash
    @echo off
    start /D "C:\path\to\proxy_logic" python main_server.py
```
