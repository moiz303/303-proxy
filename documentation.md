## Компоненты системы

### 1. Браузерное расширение (Manifest V3)

**Файловая структура:**

extension/
├── manifest.json      # Конфигурация расширения
├── background.js      # Service Worker для перехвата запросов
├── popup.html         # UI всплывающего окна
├── popup.js           # Логика popup
└── icon.png           # Иконка расширения


#### background.js
Основные функции:
- Перехват HTTP/HTTPS запросов через `chrome.webRequest.onBeforeRequest`
- Перенаправление запросов на Python прокси-сервер
- Управление состоянием прокси (вкл/выкл)

#### popup.js
- Управление UI состояния
- Сохранение настроек в `chrome.storage`
- Взаимодействие с background script через `chrome.runtime`

### 2. Python прокси-сервер

**Файловая структура:**
```
├── main.py            # Точка входа, запуск сервера
├── proxy_logic.py     # Бизнес-логика обработки запросов
└── requirements.txt   # Зависимости Python
```

#### main.py
- HTTP сервер (Flask)
- Обработка входящих прокси-запросов
- Маршрутизация и обработка ошибок
- Логирование

#### proxy_logic.py
Основные модули:
- `RequestProcessor` - парсинг и валидация входящих запросов
- `ResponseHandler` - обработка и модификация ответов
- `ProxyMiddleware` - промежуточное ПО для дополнительной логики

## Протокол взаимодействия

### Запрос от расширения к прокси:
```
POST /proxy HTTP/1.1
Content-Type: application/json

{
  "url": "https://example.com/api/connect",
  "method": "GET",
  "headers": {...},
  "body": "..."
}
```

### Ответ от прокси к расширению:
```
HTTP/1.1 200 OK
Content-Type: application/json

{
  "status": 200,
  "headers": {...},
  "body": "..."
}
```

## Настройка окружения разработки

### Запуск прокси-сервера
```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
python main.py
```


## Установка расширения для разработки
1. `chrome://extensions/` → Режим разработчика → Загрузить распакованное
2. Выбрать папку `extension`
3. В `background.js` установить URL прокси-сервера разработки


## Расширение функциональности

### Добавление новой логики обработки
1. Реализовать класс в `proxy_logic.py`
2. Зарегистрировать в основном обработчике в `main.py`
3. Протестировать через расширение

### Модификация расширения
- Добавление новых permissions → обновить `manifest.json`
- Изменение UI → редактировать `popup.html` и `popup.js`
- Новая логика перехвата → модифицировать `background.js`
